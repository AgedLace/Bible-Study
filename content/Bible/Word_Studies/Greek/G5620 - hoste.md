# G5620 — ὥστε

| Lemma | Translit | Pronunciation | Short definition |
|---|---|---|---|
| ὥστε | hṓste |  | so too |

## Definition

 so too, i.e. thus therefore (in various relations of consecution, as follow)

KJV renders: (insomuch) as, so that (then), (insomuch) that, therefore, to, wherefore
